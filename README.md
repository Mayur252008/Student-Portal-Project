# Student Portal Management System

## Project Introduction
The Student Portal Management System is a console-based C++ application developed to manage student records easily.

It stores student details such as Student ID, Name, Course and Marks.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- STL Vector
- File Handling
- Exception Handling

## Features
1. Add Student
2. Search Student
3. Display All Students
4. Calculate Result and Grade
5. Save Student Records
6. Exit

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Exception Handling

## File Handling
Student records are stored in a file named `students.txt`. Records are loaded automatically when the application starts.

## How to Run the Project (Windows)

**Step 1:** Open Windows PowerShell.

**Step 2:** Navigate to the project folder:

```powershell
cd "$HOME\Downloads\Student_Portal_Mini_Project\Student_Portal_Mini_Project"
```

**Step 3:** Compile the C++ program (if needed):

```powershell
g++ StudentPortal.cpp -o StudentPortal.exe
```

**Step 4:** Run the application:

```powershell
.\StudentPortal.exe
```
